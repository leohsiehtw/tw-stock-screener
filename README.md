# tw-stock-screener 台股盤後選股

收盤後掃描全市場（上市＋上櫃＋ETF），依「先過濾、再確認、最後挑進場點」找出突破型／回測型候選，並給出建議停損與部位試算。
資料直接取自證交所與櫃買中心官方網站，程式只用 Python 內建模組，**不需要 pip 安裝任何套件**。

> **免責聲明**：本專案僅供程式與技術分析研究，不是投資建議，也不保證任何績效。資料可能延遲、缺漏或有誤，請以交易所公告為準。投資風險由使用者自行承擔。

## 快速開始（3 步驟）

不用打任何指令，只要會「在資料夾裡雙擊檔案」。

**1. 下載並解壓縮**

到 GitHub 專案頁按綠色的 **Code → Download ZIP**（或到 [Releases](https://github.com/leohsiehtw/tw-stock-screener/releases) 下載 zip）。在 zip 檔上按**右鍵 →「全部解壓縮」**，解壓縮到固定的資料夾，例如 `D:\tw-stock-screener`。

- 不要直接在 zip 裡面雙擊檔案，要先解壓縮（否則會出現「請先解壓縮」的訊息）。
- 不要放在 OneDrive 或桌面同步資料夾裡：股價資料有兩千多個小檔案，同步會很慢。
- 第一次雙擊 `.bat` 檔時，Windows 可能跳出藍色的「Windows 已保護您的電腦」（SmartScreen）：按**「其他資訊」→「仍要執行」**。也可以先在 zip 檔上按右鍵 →「內容」，勾選最下面的「解除封鎖」再解壓縮，就不會跳出來。
- 電腦要有 Python 3.9 以上。沒裝也沒關係：下一步 `setup.bat` 找不到 Python 時會問你「要不要幫你安裝？」，打 **Y** 就會幫你安裝 Python 3.12（只裝給你這個 Windows 帳號，不需要系統管理員權限，需要網路）；打 **N** 或直接按 Enter 的話，畫面會列出自己安裝的步驟。

**2. 雙擊 `setup.bat`（只要做一次）**

它會依序：檢查 Python（找不到的話會問你要不要幫你安裝）→ 問你 3 個問題（都可以直接按 Enter 用預設值）→ 問你要不要現在下載股價資料。

| 問題 | 說明 |
|---|---|
| 總資金 | 用來試算每檔候選大概可以買幾股。不想算就按 Enter 跳過 |
| 每筆風險 | 跌到停損時最多虧總資金的幾 %，可填 2%～5%，預設 2% |
| 選股範圍 | 1 = 全市場，2 = 只看自選股清單（第一次選 2 會幫你建立 `自選股.csv`，請用記事本編輯，不要用 Excel） |

第一次下載股價約需 **30～60 分鐘**（官方網站限速，程式要慢慢抓）。下載中間關掉視窗也沒關係，再雙擊一次 `setup.bat` 就會接著抓。下載完成後會直接選一次股，並用瀏覽器打開結果頁。

**3. 每天收盤後（下午 2 點半以後）雙擊 `run.bat`**

它會自動更新當天的股價、選股，然後用瀏覽器打開結果頁。成功的話視窗 15 秒後自己關閉；失敗的話視窗會停住，並用中文告訴你原因和怎麼做（對照下面的「出錯時」）。

> 想改設定：再雙擊一次 `setup.bat`，或用記事本打開 `設定.txt`。

### 結果頁怎麼看

`run.bat` 跑完會在 `結果\` 資料夾產生 `盤後選股_<日期>.html`，並自動用瀏覽器打開。這是一個獨立的網頁檔（不連網、不需要網路就能看），可以直接複製給別人。頁面由上到下是：

1. **標題與摘要**：資料日期、掃描檔數、範圍（全市場或自選股清單）、部位設定、產生時間。如果資料日期不是今天（週末、休市，或官方還沒公布），會多一條黃色提醒。
2. **候選標的**：同時通過所有關卡的股票，欄位有代號、名稱、型態（紅底「突破型」、藍底「回測型」）、收盤、漲跌%、量比、建議停損、停損距離%、部位試算和說明。有設定總資金才會出現「部位」欄。
3. **觀察名單**：已經通過第 2 關（動能）和第 3 關（量能），但型態還沒成立的股票，值得每天盯著。使用自選股清單時，標題是「自選股：過第 2、3 關但型態未到」；清單裡找不到資料的代號會在這裡用黃色提醒。
4. **各關明細**：每一檔通過了哪些關卡（✓ 通過、✗ 沒通過）。資料不足的股票和備註收在下方可展開的區塊。
5. **怎麼看這一頁**：顏色和欄位的說明、進場後的提醒與免責聲明。

操作與顏色：

- 點表格最上面的欄位名稱可以排序，再點一次反過來排；表格太長時，欄位名稱會固定在上方。
- 漲跌%：依台灣習慣，**紅色是上漲、綠色是下跌**。
- 停損距離%：3% 以內是綠色，3%～6% 是橘色，超過 6% 是紅色（停損很遠，單筆虧損會偏大）。
- 部位：「紫色」表示已經買到總資金上限，「橘色」表示不到 1 張（零股）；停損太遠或資金不足算出 0 股時會寫明。

同一個資料夾還有其他格式：

| 檔案 | 用途 |
|---|---|
| `.html` | 給人看的網頁（上面說明的） |
| `.csv` | 給 Excel 開的表格（含 BOM，Excel 直接雙擊就不會亂碼；代號寫成 `="0050"`，開頭的 0 不會被吃掉） |
| `.md` | 完整報告（純文字，內容和舊版相同） |
| `.txt` | 精簡摘要，適合貼到聊天軟體 |
| `.json` | 每檔股票的完整分析資料，給程式串接用 |

### 設定.txt

`setup.bat` 會幫你產生 `設定.txt`；也可以自己複製 `設定.範例.txt` 改名，用記事本編輯。格式是一行一個「項目=內容」，`#` 開頭是註解。

| 項目 | 預設 | 說明 |
|---|---|---|
| `capital` | `0` | 總資金（元）。`0` 或留空 = 不試算部位。可寫 `1000000` 或 `1,000,000` |
| `risk` | `2%` | 每筆風險，2%～5%。`2`、`2%`、`0.02` 都可以 |
| `mode` | `full` | `full` = 全市場；`watchlist` = 只掃描自選股清單 |
| `watchlist` | `自選股.csv` | 自選股清單檔案（`mode=watchlist` 才用到） |
| `output_dir` | `結果` | 結果存放的資料夾，可以寫完整路徑，例如 `D:\選股結果` |

規則：

- 相對路徑是相對於 `設定.txt` 所在的資料夾；重複寫同一個項目時以最後一行為準；值留空等於用預設值。
- 檔案請存成 UTF-8。用記事本另存新檔時，下方「編碼」選 UTF-8。如果存成 Big5（ANSI），程式仍然讀得懂，但會提醒你改成 UTF-8。
- 寫錯時不會默默忽略：程式會告訴你是第幾行、哪裡不對（例如 `risk=8%` 會說風險要在 2% 到 5% 之間）。看不懂的行或不認得的項目名稱會用「注意」提醒並略過。
- 命令列選項的優先順序是：命令列 > `設定.txt` > 預設值。例如 `python screener.py scan --data data --config 設定.txt --capital 500000` 會用 500000 當總資金。
- `設定.txt` 屬於個人檔案，已被 `.gitignore` 排除，不會被 git 追蹤。

### 出錯時

失敗時畫面會出現「【沒有完成】」，下面有「原因：」和「怎麼做：」，照著做就可以。`logs\` 資料夾裡也有當天的紀錄檔（`run_<日期>.log`、`setup.log`）。結束代碼（exit code）對照：

| 代碼 | 原因 | 怎麼做 |
|---|---|---|
| 0 | 成功 | — |
| 1 | 程式發生未預期的錯誤 | 把畫面上的錯誤訊息（或紀錄檔）貼到 GitHub Issues 回報 |
| 2 | 命令列選項打錯（只會在手動執行 `python` 指令時出現） | 照畫面上的用法提示修正 |
| 3 | 連不上證交所或櫃買中心的網站（程式會先自動重試 3 次，約 2 分鐘） | 確認瀏覽器打得開 https://www.twse.com.tw/ 再執行一次；已抓到的資料會保留 |
| 4 | 官方網站暫時沒有正常回應，或回傳的格式和程式認得的不一樣 | 等 30 分鐘以上再執行（只會補抓缺的日期）；一直失敗的話看有沒有新版本或開 Issue |
| 5 | 官方還沒提供完整資料（上市有、上櫃還沒有） | 30 分鐘後再執行一次 |
| 6 | 還沒有任何股價資料 | 雙擊 `setup.bat` 並選擇下載，或執行 `python fetch_data.py backfill` |
| 7 | 自選股清單有問題（找不到檔案、第一列沒有「代號」、沒有任何代號、清單裡的代號都找不到資料） | 照畫面說明修改 `自選股.csv`；不用的話把 `設定.txt` 的 `mode` 改成 `full` |
| 8 | 檔案編碼不對（`自選股.csv` 或 `設定.txt` 是 UTF-16 等讀不懂的編碼），或命令列視窗不是 UTF-8 | 用記事本另存新檔，編碼選 UTF-8；或改用雙擊 `run.bat` |
| 9 | `設定.txt` 有問題 | 看畫面上說的行號修改，或重新雙擊 `setup.bat` |
| 20 | 找不到 Python（或版本低於 3.9），或 `setup.bat` 的自動安裝沒有完成 | 雙擊 `setup.bat`，問「要不要幫你安裝？」時打 Y；或到 https://www.python.org/downloads/ 自己安裝最新版 Python 3，再雙擊一次 |
| 21 | 找不到 `screener.py`（沒解壓縮，或只複製了 `.bat` 檔） | 在 zip 上按右鍵「全部解壓縮」，再雙擊解壓縮後資料夾裡的 `setup.bat` |
| 22 | Windows 打不開程式所在的資料夾路徑 | 把整個資料夾複製到本機磁碟（例如 `D:\tw-stock-screener`） |

## 進階使用（命令列）

以下是不用 `.bat`、直接用命令列操作的完整說明。一般使用者不需要看。

### 1. 需求

- Windows（`setup.bat`、`run.bat` 是批次檔；`fetch_data.py`、`screener.py` 本身不依賴 Windows，在其他系統用 `python3` 直接執行也可以）
- Python 3.9 以上（作者以 3.12 驗證）。確認方式：

  ```
  python --version
  ```

  顯示 `Python 3.x.x` 即可。若出現「找不到 python」，可以雙擊 `setup.bat`，它會問你要不要幫你安裝（見「常見問題」的「`setup.bat` 怎麼幫我裝 Python？」）；或自己到 https://www.python.org/downloads/ 安裝，安裝時勾選 **Add python.exe to PATH**。
- 網路能連到 `www.twse.com.tw`（證交所）與 `www.tpex.org.tw`（櫃買中心）
- 磁碟空間約 100 MB（快取與整理後的資料，實測約 70 MB，之後每天增加）

### 2. 取得程式

任選一種：

- **下載 zip**：到 [Releases](https://github.com/leohsiehtw/tw-stock-screener/releases) 下載最新的 `tw-stock-screener-vX.Y.Z.zip`，解壓縮到你想放的資料夾（例如 `D:\tw-stock-screener`）。
- **git clone**：

  ```
  git clone https://github.com/leohsiehtw/tw-stock-screener.git
  ```

之後所有命令列指令都在這個資料夾裡執行（在資料夾空白處按 Shift＋右鍵 →「在此處開啟 PowerShell 視窗」，或 `cd` 進去）。

建議資料夾路徑不要放在雲端同步目錄（OneDrive 等），避免大量小檔案拖慢同步。

資料夾內容：

| 檔案 | 用途 |
|---|---|
| `screener.py` | 選股主程式 |
| `fetch_data.py` | 抓全市場日 K、除權息還原，建立 `data/` |
| `setup.bat` | 初次設定精靈：檢查 Python（找不到時可幫你安裝）、問幾個問題、產生 `設定.txt`、下載資料 |
| `run.bat` | 每日一鍵：更新資料、選股、用瀏覽器打開結果頁 |
| `run_daily.bat` | 給排程用的相容包裝：等於 `run.bat`，但不暫停、不開瀏覽器 |
| `設定.範例.txt` | 設定檔範例（`setup.bat` 會依它產生 `設定.txt`） |
| `設定.txt` | 你的設定（`setup.bat` 產生，個人檔案，不進 git） |
| `自選股.範例.csv` | 自選股清單範例 |
| `tests/` | 自動化測試（`python -m unittest discover -s tests`，不需要網路） |
| `CHANGELOG.md`、`LICENSE` | 更新紀錄、授權 |
| `data/` | 每檔股票一個 `<代號>.csv`（程式產生） |
| `cache/` | 原始每日快照與除權息事件（程式產生，可續跑） |
| `結果/` | 每日選股結果（`run.bat` 產生） |
| `logs/` | 執行紀錄（`run.bat`、`setup.bat` 產生） |

### 3. 第一次回補資料

第一次使用要先把歷史日 K 抓下來（週 MACD 需要約 35 週暖機，所以預設回補約 430 天）：

```
python fetch_data.py backfill
```

- **耗時**：約 30～60 分鐘。為了避免被官方網站封鎖，每次請求間隔 3.5 秒，上市與上櫃各一個請求，約 285 個交易日。請讓視窗開著等它跑完。
- **進度**：每抓一天印一行，例如 `[18/308] 2025-09-12 ok`。
- **會產生**：`cache/`（每日原始快照、除權息事件）與 `data/`（約 2300 個 csv，已還原除權息，最後一步一次建好）。`結果/`、`logs/` 在第一次執行 `setup.bat` 或 `run.bat` 時才建立。
- **中斷後續跑**：直接再執行同一行指令。已抓過的日期（含休市日）會跳過，只補沒抓的；寫檔先寫 `.tmp` 再替換，中途關掉視窗不會留下半個檔。
- **指定範圍**（日期格式 `YYYYMMDD`）：

  ```
  python fetch_data.py backfill --start 20250801 --end 20261022
  ```

  不給的話預設是「今天往前 430 天」到今天。
- 週末不發請求；平日若官方回「沒有資料」且日期已過，視為休市並記錄，不會重抓。
- 若結束時顯示「【沒有完成】」並附上原因（exit code 4：官方網站回應異常；exit code 5：有幾天只抓到上市、上櫃還沒資料；exit code 3：連不上網站，重試 3 次後停止），代表有幾天沒抓齊。重跑同一行指令即可補齊並重建（見「出錯時」的代碼對照）。

回補完成後可先試掃一次：

```
python screener.py scan --data data --out 盤後選股.md
```

### 4. 每天怎麼跑

**手動**（最簡單）：收盤後雙擊 `run.bat`，或在 cmd 視窗執行（PowerShell 要加 `.\`）：

```
.\run.bat
```

它會依序：

1. 找 Python（`TWSTOCK_PY` → `python` → `py -3` → `python3`，每個都真的執行過、確認 3.9 以上才用）。
2. 執行 `fetch_data.py daily` 補最新交易日並重建 `data/`。**週末也會執行**（只補缺的、不會等待），所以週末打開也是最新的。
3. 讀 `cache\latest.txt` 得到最新交易日，並說明狀況：已經更新到今天／今天是週末／今天還沒有新資料（休市或官方還沒公布），然後用最近一個交易日的資料選股。這只是提示，不會中止。
4. 執行 `screener.py scan`：有 `設定.txt` 就用它（`--config 設定.txt`），沒有就用預設值（全市場、不試算部位）。每次都會重新產生 `結果\盤後選股_<日期>.html/.csv/.md/.txt/.json` 並用瀏覽器打開 html。
5. 全部紀錄寫到 `logs\run_<今天日期>.log`。成功時視窗 15 秒後自己關閉；失敗時停住，等你看完訊息再按任意鍵。

`run.bat force` 仍然可以執行，但沒有作用（舊版用來略過週末檢查，現在不需要）。

**什麼時候跑**：收盤（13:30）之後。如果執行時官方資料還沒公布，`fetch_data.py daily` 會每 10 分鐘重試，直到 16:00；16:00 還沒有就當作今天休市。13:30 之前執行不會等待（會直接用前一個交易日的資料）。實務上建議 14:30 之後再跑，比較不會空等；等待中想離開可以直接關掉視窗，晚點再執行。

**休市日**（國定假日、颱風假）：官方查不到當天資料，程式視為休市，不會出錯，用前一個交易日的資料選股。若平日休市又在 13:30～16:00 之間執行，會先等到 16:00 才結束。

> `run.bat` 會讀 `設定.txt`，所以總資金、風險、自選股範圍都在 `設定.txt` 設定（見上面的「設定.txt」）。`run_daily.bat` 是給舊的排程用的相容包裝：等於 `run.bat`，但不暫停也不開瀏覽器。

**Python 不在 PATH 時**：先設定環境變數 `TWSTOCK_PY` 指向 `python.exe`：

```
set TWSTOCK_PY=C:\Path\To\python.exe
run.bat
```

#### 建議的每日流程

1. 收盤後（14:30 之後）雙擊 `run.bat`。
2. 看自動打開的結果頁，先看「候選標的」。
3. 對每檔候選，看「型態」與「說明」是否符合你的交易想法，用「建議停損」與「停損距離%」評估風險報酬；停損距離太大（單筆虧損超過你能接受的範圍）的就放棄，不要為了進場而放寬停損。
4. 看「部位」欄確認股數與金額（要先在 `設定.txt` 設定總資金）。
5. 進場後以「建議停損」為出場底線；之後停利用移動停損（跟著月線或 5 日線上移）。程式只負責選股與算停損，不下單、不追蹤持股。

以上是這套規則的設計用法，不構成投資建議。

輸出有五種格式（`run.bat` 全部產生，放在 `結果\`；網頁和 csv 的看法見上面的「結果頁怎麼看」）：

#### 候選標的表

下面是 2026-10-22 全市場掃描的真實節錄：

```
# 盤後選股 2026-10-22

掃描 2301 檔，資料有效 2271 檔。

## 候選標的（23 檔）

| 代號 | 名稱 | 型態 | 收盤 | 漲跌% | 量比 | 建議停損 | 停損距離% | 說明 |
|---|---|---|---|---|---|---|---|---|
| 5432 | 新門 | 回測型 | 188.5 | -0.79 | 0.75 | 180.59 | 4.2 | 近 20 日沿月線，量縮 0.75 倍回測 MA20 止跌；停損：跌破 MA20 181.5 或今日低點 182.5 |
| 00646 | 元大S&P500 | 回測型 | 78.95 | -0.32 | 0.6 | 77.76 | 1.5 | 近 20 日沿月線，量縮 0.6 倍回測 MA20 止跌；停損：跌破 MA20 78.16 或今日低點 78.75 |
| 2881 | 富邦金 | 回測型 | 158.5 | 0.0 | 0.53 | 154.47 | 2.5 | 近 20 日沿月線，量縮 0.53 倍回測 MA20 止跌；停損：跌破 MA20 155.25 或今日低點 157.5 |

部位試算（單筆虧損 = 總資金 × 比例）：

- 00646 元大S&P500：2% → 12666 股（約 999,981 元）、5% → 12666 股（約 999,981 元）
```

（個股與 ETF 皆為示例輸出，不是推薦。實際輸出只列出節錄的列，且會依你的資料日期而不同。）

各欄位意思：

| 欄位 | 意思 |
|---|---|
| 型態 | **突破型**：整理後帶量長紅突破；**回測型**：沿月線上行、量縮回測月線止跌。兩者的判斷見下方「關卡」 |
| 收盤 | 當日實際收盤價（未還原，和看盤軟體一致） |
| 漲跌% | 相對前一交易日收盤的漲跌幅（用還原價計算，除權息日不會失真） |
| 量比 | 今日成交量 ÷ 前 5 日均量（不含今天）。突破型要求 > 1.3；回測型要求 < 0.8（量縮） |
| 建議停損 | 依型態算出的停損價（實際價位）。突破型：長紅 K 低點與 MA20 取較近者；回測型：MA20 與當日低點取較低者再減 0.5% |
| 停損距離% | （收盤 − 建議停損）÷ 收盤。越小代表單筆虧損空間越窄，但也越容易被洗出場 |
| 說明 | 觸發的型態細節與停損依據（突破型會註明是「箱型整理後」或「布林縮口後」、「今日突破」或「昨日突破、今日回測守住」） |

**部位試算**（加 `--capital 總資金` 才會出現）：用「單筆虧損 = 總資金 × 比例」反推股數，股數 = 總資金 × 比例 ÷（收盤 − 建議停損），且不超過總資金買得起的股數。每檔列兩種比例：`--risk`（預設 2%）與固定的 5%。1 張 = 1000 股。

#### 各關明細表

報告最後一張表列出每一檔通過了哪些關卡：

| 欄位 | 意思 | 打勾（✓）的條件 |
|---|---|---|
| 0 週線 | 週線方向 | 週 MACD 的 DIF > 0（零軸上）或週柱剛翻紅；收盤在週 MA13、週 MA26 之上；且不是週 MA5 < MA13 < MA26 的空頭排列 |
| 1 趨勢 | 日線趨勢 | 收盤 > MA60、MA20 > MA60、MA20 不下彎、MA60 上彎 |
| 2 動能 | MACD 動能 | 日 OSC（柱狀體）今天由負翻正；或 3 日內 DIF 上穿 DEA 且今日柱 > 昨日柱 |
| 3 量能 | 帶量上攻 | 今日量 > 前 5 日均量 × 1.3，且收紅、收盤高於昨收 |
| A 突破 | 突破型 | 通過 0～3 關，且前 20 日箱型（高低差 ≤ 12%）或布林縮口後，帶量長紅 K（實體 ≥ 3%）收在布林上軌之上；今天突破，或昨天突破、今天回測守住 |
| B 回測 | 回測型 | 通過 0～1 關（不看 2、3 關），近 20 日至少 80% 收在 MA20 上、MA20 上彎，今天低點回到 MA20 ±2% 內、收在 MA20 上止跌，量 < 5 日均量 × 0.8 |
| 量比 | 同上 | — |
| OSC 昨→今 | 日 MACD 柱狀體昨天與今天的值 | 由負轉正代表動能轉強 |

真實節錄：

```
| 代號 | 名稱 | 收盤 | 0 週線 | 1 趨勢 | 2 動能 | 3 量能 | A 突破 | B 回測 | 量比 | OSC 昨→今 |
|---|---|---|---|---|---|---|---|---|---|---|
| 2330 | 台積電 | 2385.0 | ✗ | ✗ | ✗ | ✗ | ✗ | ✗ | 0.83 | -17.59 → -18.71 |
| 2881 | 富邦金 | 158.5 | ✓ | ✓ | ✗ | ✗ | ✗ | ✓ | 0.53 | -0.37 → -0.38 |
```

例如富邦金通過第 0、1 關，且符合回測型 B，所以出現在候選表；台積電沒有通過任何關卡，不會被列入。

#### 「自選股：過第 2、3 關但型態未到」

`.md` 只在使用 `--list` 時出現；`.html` 一律會有（全市場時叫「觀察名單」）。它列出你清單裡「已經通過動能（第 2 關）和量能（第 3 關），但突破型／回測型的型態條件還沒成立」的股票。意思是這些股票已經在動、有量，值得每天盯著，等型態成立（轉進候選表）再決定要不要進場。

### 6. 指令與選項完整說明

#### `fetch_data.py`（抓資料）

| 指令 | 說明 |
|---|---|
| `python fetch_data.py backfill [--start YYYYMMDD] [--end YYYYMMDD]` | 回補歷史，可中斷續跑。`--start` 預設為今天往前 430 天，`--end` 預設為今天。結束時重建 `data/` |
| `python fetch_data.py daily` | 補最新交易日（從快取最後一天往前 14 天掃到今天，已有的跳過），重新抓當月與上月除權息，重建 `data/`。快取是空的會要你先跑 `backfill`。13:30～16:00 資料未出會每 10 分鐘重試 |
| `python fetch_data.py build` | 不連網，只用 `cache/` 重建 `data/`（例如手動修過快取之後） |

`data/<代號>.csv` 欄位：`date,open,high,low,close,volume,raw_close,name`。`open/high/low/close` 是還原權息價，`raw_close` 是當日實際收盤，`volume` 單位是股，`name` 是股票名稱。

#### `screener.py scan`（選股）

```
python screener.py scan --data data [--config 設定.txt] [--list 自選股.csv] [--capital 總資金] [--risk 0.02]
                        [--out 報告.md] [--txt 摘要.txt] [--json 完整.json]
                        [--html 報告.html] [--csv 表格.csv] [--out-dir 結果資料夾] [--open]
```

| 選項 | 說明 | 預設 |
|---|---|---|
| `--data DIR` | 資料資料夾（必填），每檔一個 `<代號>.csv`（或 `.json`） | — |
| `--list 檔案` | 自選股清單。**只掃描清單內的股票**，並多出「自選股」段落（見第 7 節） | 不給＝掃全市場 |
| `--config 檔案` | 讀 `設定.txt`（capital、risk、mode、watchlist、output_dir）。`mode=watchlist` 時等於自動加上 `--list`，並預設存到 `output_dir` | 不給＝不讀設定檔 |
| `--capital 金額` | 總資金（元），啟用部位試算 | 設定檔的 `capital`；都沒有＝不試算 |
| `--risk 比例` | 單筆虧損占總資金比例，另外固定再試算 5% | 設定檔的 `risk`；都沒有＝`0.02` |
| `--out 檔案` | 完整報告（Markdown）。不給（也沒有 `--out-dir`）的話印到螢幕 | 印到螢幕 |
| `--txt 檔案` | 精簡摘要 | 不輸出 |
| `--json 檔案` | 每檔完整分析資料 | 不輸出 |
| `--html 檔案` | 網頁報告（單一檔案，不連外部資源） | 不輸出 |
| `--csv 檔案` | Excel 用的表格（UTF-8 含 BOM） | 不輸出 |
| `--out-dir 資料夾` | 一次輸出 `盤後選股_<日期>.html/.csv/.md/.txt/.json` 五個檔案到這個資料夾（資料夾不存在會建立）；個別的 `--out`、`--html` 等仍然優先 | 設定檔的 `output_dir`；都沒有＝不輸出 |
| `--open` | 產生後用預設瀏覽器打開 html（需要有 html 輸出）。環境變數 `TWSTOCK_NO_OPEN` 有設定時略過 | 不打開 |

範例：

```
python screener.py scan --data data --capital 1000000 --out 盤後選股.md --txt 盤後選股.txt
python screener.py scan --data data --list 自選股.csv --capital 1000000 --out 自選股報告.md
```

資料不足 80 個交易日的股票會在報告最後標示錯誤，不參與判斷。

### 7. 自選股清單

1. 複製範例：

   ```
   copy 自選股.範例.csv 自選股.csv
   ```
2. 用記事本等文字編輯器編輯。格式（逗號分隔，第一列為欄位名稱）：

   ```
   代號,名稱,備註
   2330,台積電,範例
   0050,元大台灣50,範例
   ```

   - `代號` 為必填；`名稱`、`備註` 可留空。
   - 編碼用 **UTF-8**（有無 BOM 皆可）。記事本另存新檔時，編碼選「UTF-8」。存成 Big5（ANSI）程式也讀得懂，但會提醒你改；UTF-16 讀不懂（結束代碼 8）。
   - 檔名要正好是 `自選股.csv`；Windows 隱藏副檔名時，常會不小心變成 `自選股.csv.txt`，程式找不到時會提醒你。
   - **不要用 Excel 編輯**：Excel 會把 `0050` 變成 `50`，造成找不到股票。若一定要用，請把代號欄設為「文字」格式。
3. 使用：在 `設定.txt` 把 `mode` 改成 `watchlist`（`setup.bat` 第 3 題選 2 也會幫你設好），之後 `run.bat` 就只掃描清單內的股票；或用命令列：`python screener.py scan --data data --list 自選股.csv --out 自選股報告.md`

`--list` 與不加 `--list` 的差別：

| | 不加 `--list` | 加 `--list` |
|---|---|---|
| 掃描範圍 | 全市場（約 2300 檔） | 只有清單內的股票 |
| 報告內容 | 候選標的＋各關明細 | 候選標的＋「過第 2、3 關但型態未到」＋各關明細 |
| 用途 | 每天找新標的 | 盯著已經研究過的股票 |

自選股清單屬於個人資料，已被 `.gitignore` 排除，不會被 git 追蹤。

### 8. 調整門檻

所有門檻都集中在 `screener.py` 開頭的 `P`，直接修改數字、存檔，下次執行就生效（`data/` 不用重抓）。

| 參數 | 預設 | 意思 |
|---|---|---|
| `wk_ma` | `(13, 26)` | 第 0 關使用的週均線週數（週 MA13、MA26） |
| `vol_mult` | `1.3` | 第 3 關量能倍數：今日量須大於前 N 日均量的幾倍；突破的長紅 K 也用這個倍數 |
| `vol_days` | `5` | 計算均量的天數 |
| `slope_days` | `5` | 判斷均線上彎／下彎時，和幾天前比較 |
| `cross_within` | `3` | 第 2 關：DIF 上穿 DEA 允許發生在幾天內 |
| `box_days` | `20` | 箱型整理的觀察天數 |
| `box_range` | `0.12` | 箱型高低差 ÷ 均價的上限（12%） |
| `squeeze_lookback` | `120` | 布林縮口的比較期間（天） |
| `squeeze_pct` | `0.25` | 帶寬落在期間內最低 25% 視為縮口 |
| `long_red` | `0.03` | 長紅 K 的實體下限（3%） |
| `ride_days` | `20` | 回測型「沿月線」的觀察天數 |
| `ride_ratio` | `0.8` | 回測型：期間內至少 80% 的天數收在 MA20 之上 |
| `pull_near` | `0.02` | 回測型：最低價離 MA20 在 ±2% 內 |
| `pull_vol` | `0.8` | 回測型量縮：今日量 < 前 5 日均量 × 0.8 |
| `expand` | `1.2` | `pool`：布林帶寬比 5 日前擴大的倍數 |

門檻調得越寬，候選越多、雜訊也越多；調整前建議先留一份 `screener.py` 備份。

### 9. 排程自動執行（選用）

> **選用功能，需要你自行同意才建立。** 本專案不會自動建立排程。排程會讓程式在每個平日自動執行並連網抓資料；不需要的話隨時可以刪除。

用 Windows 內建的工作排程器，每個平日 15:00 執行（請把路徑改成你的資料夾，路徑含空白時整段要用跳脫的雙引號包住）：

```
schtasks /Create /TN "TwStockDaily" /TR "\"D:\tw-stock-screener\run_daily.bat\"" /SC WEEKLY /D MON,TUE,WED,THU,FRI /ST 15:00
```

管理指令：

```
schtasks /Query /TN "TwStockDaily" /V /FO LIST   :: 查看
schtasks /Run /TN "TwStockDaily"                 :: 立刻跑一次
schtasks /Delete /TN "TwStockDaily" /F           :: 刪除
```

注意：

- 電腦在排程時間沒開機的話，預設不會補跑；`daily` 會從快取最後一天往前補，所以下次執行時缺的日期會自動補上，但錯過那天的報告不會單獨產生。
- 排程請繼續指向 `run_daily.bat`：它等於 `run.bat`，但不會暫停等按鍵、不會開瀏覽器，適合背景執行。
- 排程在使用者登入狀態下執行。若 `python` 不在系統 PATH，請先設定系統環境變數 `TWSTOCK_PY`（見第 4 節）。
- 國定假日、颱風假：程式自己判斷休市，不需要另外處理。

### 10. 常見問題

**官方某天暫時沒資料，被標成休市，怎麼重抓？**
刪掉那天的快取檔（例如 2026-10-20），再用 `backfill` 只補那一天：

```
del cache\twse\20261020.json
del cache\tpex\20261020.json
python fetch_data.py backfill --start 20261020 --end 20261020
```

**除權息後某檔資料不對（價格有缺口、或還原係數怪怪的）？**
刪掉那個月的除權息快取，重抓並重建：

```
del cache\exright\twse_202610.json
del cache\exright\tpex_202610.json
python fetch_data.py backfill --start 20261001 --end 20261001
```

（`--start` 給該月任一日即可，會重抓該月到當月的除權息事件，並自動重建 `data/`。）減資、分割、反分割不會被還原（見第 11 節）。

**畫面或檔案中文變亂碼？**
- `.md`、`.txt`、`.json`、`.html` 都是 **UTF-8**，用記事本、VS Code、瀏覽器開。`.csv` 含 BOM，Excel 直接雙擊就能正確顯示中文，不用特別設定。
- 命令列直接 `scan`（沒給 `--out`）時，若視窗的編碼不是 UTF-8，程式會停下來並說明（結束代碼 8）：請改用雙擊 `run.bat`，或先執行 `chcp 65001` 並設定 `set PYTHONUTF8=1`，或加上 `--out` 存成檔案。
- 自己編輯 `自選股.csv`、`設定.txt` 時，存檔編碼請選 UTF-8。

**執行 `run.bat` 說找不到 python？**
雙擊同一個資料夾裡的 `setup.bat`，問「要不要幫你安裝？」時打 Y，它就會幫你安裝 Python（`run.bat` 本身不會安裝任何東西）。也可以自己安裝（https://www.python.org/downloads/，安裝程式若有「Add python.exe to PATH」要打勾），或設定 `TWSTOCK_PY`（見第 4 節）。

**`setup.bat` 怎麼幫我裝 Python？**
只有在電腦上找不到 Python、而且你在「要不要幫你安裝？」打 Y 的時候才會做；直接按 Enter 等於 N，什麼都不會裝，只會列出自己安裝的步驟。流程是：
1. 先試 Windows 內建的 winget：`winget install -e --id Python.Python.3.12 --scope user --accept-package-agreements --accept-source-agreements`。如果跳出「使用者帳戶控制」視窗，按「是」。
2. 電腦沒有 winget，或 winget 沒裝好，就改從 Python 官方網站下載 3.12.10 的安裝程式（`https://www.python.org/ftp/python/3.12.10/`，依電腦種類自動挑 64 位元、ARM64 或 32 位元的檔案）。畫面會印出來源網址和檔案的 SHA256；只有檔案帶著有效的 Python Software Foundation 數位簽章才會執行，簽章不對就停下來，不會執行。
3. 安裝參數是 `/quiet InstallAllUsers=0 InstallLauncherAllUsers=0 PrependPath=1 Include_test=0`（只裝給目前這個帳號、加入 PATH、不裝測試套件）。安裝程式下載後放在暫存資料夾，裝完就刪除；安裝紀錄在 `logs\python_install*.log`。
4. 裝完會在同一個視窗重新找 Python，找到就接著設定；找不到的話，關掉視窗再雙擊一次 `setup.bat`。

想移除的話：Windows「設定」→「應用程式」，解除安裝「Python 3.12」。

**裝好 Python 了，`setup.bat` 還是說找不到？**
- 剛裝完的 Python 要重新開啟的視窗才看得到：關掉視窗再雙擊一次 `setup.bat`；還是不行就重新開機。
- Windows 內建的 Microsoft Store 假 `python`（只會跳出商店）會擋住真的 Python：到 Windows「設定」→「應用程式」→「進階應用程式設定」→「應用程式執行別名」，把 `python.exe` 和 `python3.exe` 關掉。
- 也可以直接指定位置：設定環境變數 `TWSTOCK_PY` 指向 `python.exe`（見第 4 節）。

**雙擊 `.bat` 視窗一閃就消失？**
成功時視窗會停 15 秒，失敗時會停住等你按鍵。如果真的一閃而過，多半是檔案沒解壓縮就雙擊（先在 zip 上按右鍵「全部解壓縮」），或被防毒軟體擋掉；可以改開 cmd 視窗，進到資料夾後輸入 `run.bat` 看訊息。

**結果頁沒有自動打開？**
畫面上會列出檔案位置，到 `結果\` 資料夾雙擊 `盤後選股_<日期>.html` 即可。程式無法自動開瀏覽器時也會這樣提示。

**我建了 `設定.txt`，但 `run.bat` 說沒有？**
Windows 預設隱藏副檔名，用記事本存檔常變成 `設定.txt.txt`。`run.bat` 找到時會提醒你把檔名改成 `設定.txt`；到檔案總管的「檢視」勾選「副檔名」就看得到。

**Excel 開 `.csv` 會亂碼嗎？**
不會。新版輸出的 csv 有 BOM，Excel 雙擊就能正確顯示中文；代號欄寫成 `="0050"`，開頭的 0 也不會被吃掉。

**平日休市，在 13:30～16:00 之間執行會一直等嗎？**
會。官方沒有公布資料時，程式每 10 分鐘重試一次，等到 16:00 才當作休市。不想等可以關掉視窗，晚點再執行（或 13:30 之前、週末執行，不會等待）。

**執行到一半被官方封鎖或一直失敗？**
程式會自動等 10、30、90 秒重試。若還是失敗，等一段時間再執行同一行指令（可續跑）。請不要調小 `fetch_data.py` 裡的請求間隔。

**`scan` 說資料不足 80 天？**
新上市或剛補資料不久的股票天數不夠，會被標示錯誤，屬正常。確認 `backfill` 有完整跑完。

**想重新來過？**
刪除 `cache/` 與 `data/` 後重跑 `backfill`。

### 11. 資料來源與限制

來源（官方，不經第三方）：

- 上市日收盤：證交所 `rwd/zh/afterTrading/MI_INDEX`
- 上櫃日收盤：櫃買中心 `www/zh-tw/afterTrading/otc`
- 除權息：證交所 `exRight/TWT49U`、櫃買中心 `bulletin/exDailyQ`

處理方式：

- 只收 4 碼一般股與 ETF（含槓桿、反向、債券型），剔除權證、特別股、-DR；最新交易日沒成交的不輸出。
- 請求間隔 3.5 秒，失敗等 10、30、90 秒重試。
- 休市判斷：官方回「無資料」且日期已過才標記休市；當天沒資料不標記。
- 除權息還原：係數 = 參考價 ÷ 除權息前收盤價，對該日之前的 K 棒由新往舊連乘，調整 open/high/low/close，成交量不動；`data/` 每次由 `cache/` 整批重建，不會重複還原。報告中的價格顯示未還原的實際價（`raw_close`）。

限制：

- 減資、分割、反分割不調整，遇到時該檔前後價格會斷層。
- 官方網站格式或網址可能改版，改版後需更新 `fetch_data.py`。
- 過去某天若官方暫時回「無資料」會被標為休市，需依第 10 節重抓。
- 結果只反映技術面條件，沒有基本面、消息面與流動性的判斷。
