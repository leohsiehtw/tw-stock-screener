# tw-stock-screener 台股盤後選股

收盤後掃描全市場（上市＋上櫃＋ETF），依「先過濾、再確認、最後挑進場點」找出突破型／回測型候選，並給出建議停損與部位試算。
資料直接取自證交所與櫃買中心官方網站，程式只用 Python 內建模組，**不需要 pip 安裝任何套件**。

> **免責聲明**：本專案僅供程式與技術分析研究，不是投資建議，也不保證任何績效。資料可能延遲、缺漏或有誤，請以交易所公告為準。投資風險由使用者自行承擔。

## 1. 需求

- Windows（`run_daily.bat` 是批次檔；`fetch_data.py`、`screener.py` 本身不依賴 Windows，在其他系統用 `python3` 直接執行也可以）
- Python 3.9 以上（作者以 3.12 驗證）。確認方式：

  ```
  python --version
  ```

  顯示 `Python 3.x.x` 即可。若出現「找不到 python」，請到 https://www.python.org/downloads/ 安裝，安裝時勾選 **Add python.exe to PATH**。
- 網路能連到 `www.twse.com.tw`（證交所）與 `www.tpex.org.tw`（櫃買中心）
- 磁碟空間約 100 MB（快取與整理後的資料，實測約 70 MB，之後每天增加）

## 2. 取得程式

任選一種：

- **下載 zip**：到 [Releases](https://github.com/leohsiehtw/tw-stock-screener/releases) 下載最新的 `tw-stock-screener-vX.Y.Z.zip`，解壓縮到你想放的資料夾（例如 `D:\tw-stock-screener`）。
- **git clone**：

  ```
  git clone https://github.com/leohsiehtw/tw-stock-screener.git
  ```

之後所有指令都在這個資料夾裡執行（在資料夾空白處按 Shift＋右鍵 →「在此處開啟 PowerShell 視窗」，或 `cd` 進去）。

建議資料夾路徑不要放在雲端同步目錄（OneDrive 等），避免大量小檔案拖慢同步。

資料夾內容：

| 檔案 | 用途 |
|---|---|
| `screener.py` | 選股主程式 |
| `fetch_data.py` | 抓全市場日 K、除權息還原，建立 `data/` |
| `run_daily.bat` | 每日一鍵：更新資料、選股、存檔 |
| `自選股.範例.csv` | 自選股清單範例 |
| `CHANGELOG.md`、`LICENSE` | 更新紀錄、授權 |
| `data/` | 每檔股票一個 `<代號>.csv`（程式產生） |
| `cache/` | 原始每日快照與除權息事件（程式產生，可續跑） |
| `結果/` | 每日選股結果（`run_daily.bat` 產生） |
| `logs/` | 執行紀錄（`run_daily.bat` 產生） |

## 3. 第一次回補資料

第一次使用要先把歷史日 K 抓下來（週 MACD 需要約 35 週暖機，所以預設回補約 430 天）：

```
python fetch_data.py backfill
```

- **耗時**：約 30～60 分鐘。為了避免被官方網站封鎖，每次請求間隔 3.5 秒，上市與上櫃各一個請求，約 285 個交易日。請讓視窗開著等它跑完。
- **進度**：每抓一天印一行，例如 `[18/308] 2025-09-12 ok`。
- **會產生**：`cache/`（每日原始快照、除權息事件）與 `data/`（約 2300 個 csv，已還原除權息，最後一步一次建好）。`結果/`、`logs/` 在第一次執行 `run_daily.bat` 時才建立。
- **中斷後續跑**：直接再執行同一行指令。已抓過的日期（含休市日）會跳過，只補沒抓的；寫檔先寫 `.tmp` 再替換，中途關掉視窗不會留下半個檔。
- **指定範圍**（日期格式 `YYYYMMDD`）：

  ```
  python fetch_data.py backfill --start 20250801 --end 20261022
  ```

  不給的話預設是「今天往前 430 天」到今天。
- 週末不發請求；平日若官方回「沒有資料」且日期已過，視為休市並記錄，不會重抓。
- 若結束時顯示 `FAIL: N 天資料不完整（tpex-missing/error），不重建`（exit code 1），代表有幾天只抓到上市、上櫃沒資料或發生錯誤，這次**不會重建 `data/`**。重跑同一行指令即可補齊並重建。

回補完成後可先試掃一次：

```
python screener.py scan --data data --out 盤後選股.md
```

## 4. 每天怎麼跑

**手動**（最簡單）：收盤後在資料夾執行

```
.\run_daily.bat
```

在 cmd 視窗用 `run_daily.bat` 即可（PowerShell 要加 `.\`）。它會依序：

1. 判斷今天是不是週末 → 週末直接結束（`run_daily.bat force` 可略過這個檢查）。
2. 執行 `fetch_data.py daily` 補最新交易日並重建 `data/`。
3. 讀 `cache\latest.txt` 得到最新交易日；若 `結果\盤後選股_<日期>.md` 已存在，視為沒有新 K（休市），不重複選股。
4. 否則執行 `screener.py scan`，輸出 `結果\盤後選股_<日期>.md/.txt/.json`。
5. 全部紀錄寫到 `logs\run_<今天日期>.log`。

**什麼時候跑**：收盤（13:30）之後。如果執行時官方資料還沒公布，`fetch_data.py daily` 會每 10 分鐘重試，直到 16:00；16:00 還沒有就當作今天休市。13:30 之前執行不會等待。實務上建議 14:30 之後再跑，比較不會空等。

**休市日**（國定假日、颱風假）：官方查不到當天資料，程式視為休市，不產生新報告，也不會出錯。若平日休市又在 13:30～16:00 之間執行，會先等到 16:00 才結束。

> `run_daily.bat` 不帶 `--list` 與 `--capital`。要自選股清單或部位試算，請手動執行 `screener.py scan`（見第 6 節）。

**Python 不在 PATH 時**：先設定環境變數 `TWSTOCK_PY` 指向 `python.exe`：

```
set TWSTOCK_PY=C:\Path\To\python.exe
run_daily.bat
```

### 建議的每日流程

1. 收盤後（14:30 之後）執行 `run_daily.bat`。
2. 打開 `結果\盤後選股_<日期>.md`，先看「候選標的」。
3. 對每檔候選，看「型態」與「說明」是否符合你的交易想法，用「建議停損」與「停損距離%」評估風險報酬；停損距離太大（單筆虧損超過你能接受的範圍）的就放棄，不要為了進場而放寬停損。
4. 用 `--capital` 做部位試算，確認股數與金額。
5. 進場後以「建議停損」為出場底線；之後停利用移動停損（跟著月線或 5 日線上移）。程式只負責選股與算停損，不下單、不追蹤持股。

以上是這套規則的設計用法，不構成投資建議。

## 5. 怎麼看結果

輸出有三種格式（`run_daily.bat` 三種都產生，放在 `結果\`）：

| 檔案 | 內容 |
|---|---|
| `.md` | 完整報告：候選表、部位試算、各關明細 |
| `.txt` | 精簡摘要（適合貼到聊天軟體） |
| `.json` | 每檔股票的完整分析資料（程式串接用） |

### 候選標的表

下面是 2026-10-22 全市場掃描的真實節錄：

```
# 盤後選股 2026-10-22

掃描 2301 檔，資料有效 2271 檔。

## 候選標的（23 檔）

| 代號 | 名稱 | 型態 | 收盤 | 漲跌% | 量比 | 建議停損 | 停損距離% | 說明 |
|---|---|---|---|---|---|---|---|---|
| 5432 | 新門 | 回測型 | 188.5 | -0.79 | 0.75 | 180.59 | 4.2 | 近 20 日沿月線，量縮 0.75 倍回測 MA20 止跌；停損：跌破 MA20 181.5 或今日低點 182.5 |
| 00646 | 元大S&P500 | 回測型 | 78.95 | -0.32 | 0.6 | 77.76 | 1.5 | 近 20 日沿月線，量縮 0.6 倍回測 MA20 止跌；停損：跌破 MA20 78.16 或今日低點 78.75 |
| 2881 | 富邦金 | 回測型 | 158.5 | 0.0 | 0.53 | 154.47 | 2.5 | 近 20 日沿月線，量縮 0.53 倍回測 MA20 止跌；停損：跌破 MA20 155.25 或今日低點 157.5 |

部位試算（單筆虧損 = 總資金 × 比例）：

- 00646 元大S&P500：2% → 12666 股（約 999,981 元）、5% → 12666 股（約 999,981 元）
```

（個股與 ETF 皆為示例輸出，不是推薦。實際輸出只列出節錄的列，且會依你的資料日期而不同。）

各欄位意思：

| 欄位 | 意思 |
|---|---|
| 型態 | **突破型**：整理後帶量長紅突破；**回測型**：沿月線上行、量縮回測月線止跌。兩者的判斷見下方「關卡」 |
| 收盤 | 當日實際收盤價（未還原，和看盤軟體一致） |
| 漲跌% | 相對前一交易日收盤的漲跌幅（用還原價計算，除權息日不會失真） |
| 量比 | 今日成交量 ÷ 前 5 日均量（不含今天）。突破型要求 > 1.3；回測型要求 < 0.8（量縮） |
| 建議停損 | 依型態算出的停損價（實際價位）。突破型：長紅 K 低點與 MA20 取較近者；回測型：MA20 與當日低點取較低者再減 0.5% |
| 停損距離% | （收盤 − 建議停損）÷ 收盤。越小代表單筆虧損空間越窄，但也越容易被洗出場 |
| 說明 | 觸發的型態細節與停損依據（突破型會註明是「箱型整理後」或「布林縮口後」、「今日突破」或「昨日突破、今日回測守住」） |

**部位試算**（加 `--capital 總資金` 才會出現）：用「單筆虧損 = 總資金 × 比例」反推股數，股數 = 總資金 × 比例 ÷（收盤 − 建議停損），且不超過總資金買得起的股數。每檔列兩種比例：`--risk`（預設 2%）與固定的 5%。1 張 = 1000 股。

### 各關明細表

報告最後一張表列出每一檔通過了哪些關卡：

| 欄位 | 意思 | 打勾（✓）的條件 |
|---|---|---|
| 0 週線 | 週線方向 | 週 MACD 的 DIF > 0（零軸上）或週柱剛翻紅；收盤在週 MA13、週 MA26 之上；且不是週 MA5 < MA13 < MA26 的空頭排列 |
| 1 趨勢 | 日線趨勢 | 收盤 > MA60、MA20 > MA60、MA20 不下彎、MA60 上彎 |
| 2 動能 | MACD 動能 | 日 OSC（柱狀體）今天由負翻正；或 3 日內 DIF 上穿 DEA 且今日柱 > 昨日柱 |
| 3 量能 | 帶量上攻 | 今日量 > 前 5 日均量 × 1.3，且收紅、收盤高於昨收 |
| A 突破 | 突破型 | 通過 0～3 關，且前 20 日箱型（高低差 ≤ 12%）或布林縮口後，帶量長紅 K（實體 ≥ 3%）收在布林上軌之上；今天突破，或昨天突破、今天回測守住 |
| B 回測 | 回測型 | 通過 0～1 關（不看 2、3 關），近 20 日至少 80% 收在 MA20 上、MA20 上彎，今天低點回到 MA20 ±2% 內、收在 MA20 上止跌，量 < 5 日均量 × 0.8 |
| 量比 | 同上 | — |
| OSC 昨→今 | 日 MACD 柱狀體昨天與今天的值 | 由負轉正代表動能轉強 |

真實節錄：

```
| 代號 | 名稱 | 收盤 | 0 週線 | 1 趨勢 | 2 動能 | 3 量能 | A 突破 | B 回測 | 量比 | OSC 昨→今 |
|---|---|---|---|---|---|---|---|---|---|---|
| 2330 | 台積電 | 2385.0 | ✗ | ✗ | ✗ | ✗ | ✗ | ✗ | 0.83 | -17.59 → -18.71 |
| 2881 | 富邦金 | 158.5 | ✓ | ✓ | ✗ | ✗ | ✗ | ✓ | 0.53 | -0.37 → -0.38 |
```

例如富邦金通過第 0、1 關，且符合回測型 B，所以出現在候選表；台積電沒有通過任何關卡，不會被列入。

### 「自選股：過第 2、3 關但型態未到」

只在使用 `--list` 時出現。它列出你清單裡「已經通過動能（第 2 關）和量能（第 3 關），但突破型／回測型的型態條件還沒成立」的股票。意思是這些股票已經在動、有量，值得每天盯著，等型態成立（轉進候選表）再決定要不要進場。

## 6. 指令與選項完整說明

### `fetch_data.py`（抓資料）

| 指令 | 說明 |
|---|---|
| `python fetch_data.py backfill [--start YYYYMMDD] [--end YYYYMMDD]` | 回補歷史，可中斷續跑。`--start` 預設為今天往前 430 天，`--end` 預設為今天。結束時重建 `data/` |
| `python fetch_data.py daily` | 補最新交易日（從快取最後一天往前 14 天掃到今天，已有的跳過），重新抓當月與上月除權息，重建 `data/`。快取是空的會要你先跑 `backfill`。13:30～16:00 資料未出會每 10 分鐘重試 |
| `python fetch_data.py build` | 不連網，只用 `cache/` 重建 `data/`（例如手動修過快取之後） |

`data/<代號>.csv` 欄位：`date,open,high,low,close,volume,raw_close,name`。`open/high/low/close` 是還原權息價，`raw_close` 是當日實際收盤，`volume` 單位是股，`name` 是股票名稱。

### `screener.py scan`（選股）

```
python screener.py scan --data data [--list 自選股.csv] [--capital 總資金] [--risk 0.02]
                        [--out 報告.md] [--txt 摘要.txt] [--json 完整.json]
```

| 選項 | 說明 | 預設 |
|---|---|---|
| `--data DIR` | 資料資料夾（必填），每檔一個 `<代號>.csv`（或 `.json`） | — |
| `--list 檔案` | 自選股清單。**只掃描清單內的股票**，並多出「自選股」段落（見第 7 節） | 不給＝掃全市場 |
| `--capital 金額` | 總資金（元），啟用部位試算 | 不給＝不試算 |
| `--risk 比例` | 單筆虧損占總資金比例，另外固定再試算 5% | `0.02` |
| `--out 檔案` | 完整報告（Markdown）。不給的話印到螢幕 | 印到螢幕 |
| `--txt 檔案` | 精簡摘要 | 不輸出 |
| `--json 檔案` | 每檔完整分析資料 | 不輸出 |

範例：

```
python screener.py scan --data data --capital 1000000 --out 盤後選股.md --txt 盤後選股.txt
python screener.py scan --data data --list 自選股.csv --capital 1000000 --out 自選股報告.md
```

資料不足 80 個交易日的股票會在報告最後標示錯誤，不參與判斷。

### `screener.py pool`（找自選股候選）

```
python screener.py pool --data data [--out 自選股候選.csv]
```

列出「收盤在季線（MA60）之上，且布林帶寬比 5 日前擴大 20% 以上」的股票，MACD 剛由負轉正的排前面。輸出 csv 欄位：`代號,名稱,收盤,帶寬擴張,MACD剛轉正`，可挑幾檔放進自選股清單。不給 `--out` 會印到螢幕。

### `screener.py add`（進階，一般不需要）

```
python screener.py add --data DIR --bars 今日.csv
```

把另外來源的 K 棒（欄位 `code,date,open,high,low,close,volume`）併進資料夾。**不要和 `fetch_data.py` 產生的 `data/` 混用**：`add` 會丟掉 `raw_close` 與 `name` 欄，且與快取不一致。

## 7. 自選股清單

1. 複製範例：

   ```
   copy 自選股.範例.csv 自選股.csv
   ```
2. 用記事本等文字編輯器編輯。格式（逗號分隔，第一列為欄位名稱）：

   ```
   代號,名稱,備註
   2330,台積電,範例
   0050,元大台灣50,範例
   ```

   - `代號` 為必填；`名稱`、`備註` 可留空。
   - 編碼用 **UTF-8**（有無 BOM 皆可）。記事本另存新檔時，編碼選「UTF-8」。
   - **不要用 Excel 編輯**：Excel 會把 `0050` 變成 `50`，造成找不到股票。若一定要用，請把代號欄設為「文字」格式。
3. 使用：`python screener.py scan --data data --list 自選股.csv --out 自選股報告.md`

`--list` 與不加 `--list` 的差別：

| | 不加 `--list` | 加 `--list` |
|---|---|---|
| 掃描範圍 | 全市場（約 2300 檔） | 只有清單內的股票 |
| 報告內容 | 候選標的＋各關明細 | 候選標的＋「過第 2、3 關但型態未到」＋各關明細 |
| 用途 | 每天找新標的 | 盯著已經研究過的股票 |

自選股清單屬於個人資料，已被 `.gitignore` 排除，不會被 git 追蹤。

## 8. 調整門檻

所有門檻都集中在 `screener.py` 開頭的 `P`，直接修改數字、存檔，下次執行就生效（`data/` 不用重抓）。

| 參數 | 預設 | 意思 |
|---|---|---|
| `wk_ma` | `(13, 26)` | 第 0 關使用的週均線週數（週 MA13、MA26） |
| `vol_mult` | `1.3` | 第 3 關量能倍數：今日量須大於前 N 日均量的幾倍；突破的長紅 K 也用這個倍數 |
| `vol_days` | `5` | 計算均量的天數 |
| `slope_days` | `5` | 判斷均線上彎／下彎時，和幾天前比較 |
| `cross_within` | `3` | 第 2 關：DIF 上穿 DEA 允許發生在幾天內 |
| `box_days` | `20` | 箱型整理的觀察天數 |
| `box_range` | `0.12` | 箱型高低差 ÷ 均價的上限（12%） |
| `squeeze_lookback` | `120` | 布林縮口的比較期間（天） |
| `squeeze_pct` | `0.25` | 帶寬落在期間內最低 25% 視為縮口 |
| `long_red` | `0.03` | 長紅 K 的實體下限（3%） |
| `ride_days` | `20` | 回測型「沿月線」的觀察天數 |
| `ride_ratio` | `0.8` | 回測型：期間內至少 80% 的天數收在 MA20 之上 |
| `pull_near` | `0.02` | 回測型：最低價離 MA20 在 ±2% 內 |
| `pull_vol` | `0.8` | 回測型量縮：今日量 < 前 5 日均量 × 0.8 |
| `expand` | `1.2` | `pool`：布林帶寬比 5 日前擴大的倍數 |

門檻調得越寬，候選越多、雜訊也越多；調整前建議先留一份 `screener.py` 備份。

## 9. 排程自動執行（選用）

> **選用功能，需要你自行同意才建立。** 本專案不會自動建立排程。排程會讓程式在每個平日自動執行並連網抓資料；不需要的話隨時可以刪除。

用 Windows 內建的工作排程器，每個平日 15:00 執行（請把路徑改成你的資料夾，路徑含空白時整段要用跳脫的雙引號包住）：

```
schtasks /Create /TN "TwStockDaily" /TR "\"D:\tw-stock-screener\run_daily.bat\"" /SC WEEKLY /D MON,TUE,WED,THU,FRI /ST 15:00
```

管理指令：

```
schtasks /Query /TN "TwStockDaily" /V /FO LIST   :: 查看
schtasks /Run /TN "TwStockDaily"                 :: 立刻跑一次
schtasks /Delete /TN "TwStockDaily" /F           :: 刪除
```

注意：

- 電腦在排程時間沒開機的話，預設不會補跑；`daily` 會從快取最後一天往前補，所以下次執行時缺的日期會自動補上，但錯過那天的報告不會單獨產生。
- 排程在使用者登入狀態下執行。若 `python` 不在系統 PATH，請先設定系統環境變數 `TWSTOCK_PY`（見第 4 節）。
- 國定假日、颱風假：程式自己判斷休市，不需要另外處理。

## 10. 常見問題

**官方某天暫時沒資料，被標成休市，怎麼重抓？**
刪掉那天的快取檔（例如 2026-10-20），再用 `backfill` 只補那一天：

```
del cache\twse\20261020.json
del cache\tpex\20261020.json
python fetch_data.py backfill --start 20261020 --end 20261020
```

**除權息後某檔資料不對（價格有缺口、或還原係數怪怪的）？**
刪掉那個月的除權息快取，重抓並重建：

```
del cache\exright\twse_202610.json
del cache\exright\tpex_202610.json
python fetch_data.py backfill --start 20261001 --end 20261001
```

（`--start` 給該月任一日即可，會重抓該月到當月的除權息事件，並自動重建 `data/`。）減資、分割、反分割不會被還原（見第 11 節）。

**畫面或檔案中文變亂碼？**
- 所有輸出檔都是 **UTF-8**，用記事本、VS Code 等支援 UTF-8 的編輯器開；Excel 直接開 `.md`／`.csv` 可能亂碼，請用「資料 → 從文字／CSV」並選 UTF-8。
- 命令列直接 `scan`（沒給 `--out`）時，若視窗的編碼不是 UTF-8 可能會出錯或亂碼：請改用 `--out` 存成檔案，或先執行 `chcp 65001` 並設定 `set PYTHONUTF8=1` 再跑。
- 自己編輯 `自選股.csv` 時，存檔編碼請選 UTF-8。

**執行 `run_daily.bat` 說找不到 python？**
設定 `TWSTOCK_PY`（見第 4 節）或重新安裝 Python 並勾選 Add to PATH。

**執行到一半被官方封鎖或一直失敗？**
程式會自動等 10、30、90 秒重試。若還是失敗，等一段時間再執行同一行指令（可續跑）。請不要調小 `fetch_data.py` 裡的請求間隔。

**`scan` 說資料不足 80 天？**
新上市或剛補資料不久的股票天數不夠，會被標示錯誤，屬正常。確認 `backfill` 有完整跑完。

**想重新來過？**
刪除 `cache/` 與 `data/` 後重跑 `backfill`。

## 11. 資料來源與限制

來源（官方，不經第三方）：

- 上市日收盤：證交所 `rwd/zh/afterTrading/MI_INDEX`
- 上櫃日收盤：櫃買中心 `www/zh-tw/afterTrading/otc`
- 除權息：證交所 `exRight/TWT49U`、櫃買中心 `bulletin/exDailyQ`

處理方式：

- 只收 4 碼一般股與 ETF（含槓桿、反向、債券型），剔除權證、特別股、-DR；最新交易日沒成交的不輸出。
- 請求間隔 3.5 秒，失敗等 10、30、90 秒重試。
- 休市判斷：官方回「無資料」且日期已過才標記休市；當天沒資料不標記。
- 除權息還原：係數 = 參考價 ÷ 除權息前收盤價，對該日之前的 K 棒由新往舊連乘，調整 open/high/low/close，成交量不動；`data/` 每次由 `cache/` 整批重建，不會重複還原。報告中的價格顯示未還原的實際價（`raw_close`）。

限制：

- 減資、分割、反分割不調整，遇到時該檔前後價格會斷層。
- 官方網站格式或網址可能改版，改版後需更新 `fetch_data.py`。
- 過去某天若官方暫時回「無資料」會被標為休市，需依第 10 節重抓。
- 結果只反映技術面條件，沒有基本面、消息面與流動性的判斷。
